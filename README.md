# Note App - Smart Note Taking App

A clean, fast note-taking app for organizing ideas, tasks, and daily notes with local storage & cloud sync.

**Live Demo:** https://your-link.vercel.app
**Repo:** https://github.com/David01Afolayan/Note-App

## Features
- Create, Edit, Delete Notes
- Categories / Tags
- Search & Filter
- Dark / Light Mode
- Local Storage + Cloud Sync
- Responsive Design

## Tech Stack
- Frontend: React / Next.js, TypeScript, Tailwind CSS
- Backend: Next.js API / Node.js
- Deployment: Vercel
